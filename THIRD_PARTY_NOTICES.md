# Third-party notices

## wordfreq and language data

This application uses the `wordfreq` Python library without exporting or redistributing a separate corpus file. The library code is available under the Apache license, and its bundled data may be redistributed under Creative Commons Attribution-ShareAlike 4.0. The installed package retains its notices and licenses.

Credit: Robyn Speer (2022), *rspeer/wordfreq: v3.0 (v3.0.2)*, Zenodo, https://doi.org/10.5281/zenodo.7199437. Project and full source acknowledgements: https://github.com/rspeer/wordfreq. Data license: https://creativecommons.org/licenses/by-sa/4.0/.

The corpus includes data derived from Google Books Ngrams (https://books.google.com/ngrams), Wikipedia (https://www.wikipedia.org), the Leeds Internet Corpus (http://corpus.leeds.ac.uk/list.html), ParaCrawl (https://paracrawl.eu), OPUS OpenSubtitles/OpenSubtitles (https://opus.nlpl.eu/OpenSubtitles.php and https://www.opensubtitles.org), and SUBTLEX word lists by Marc Brysbaert and collaborators (https://crr.ugent.be/programs-data/subtitle-frequencies). SUBTLEX is freely available data. Refer to wordfreq's documentation for the complete authorship and source terms.
