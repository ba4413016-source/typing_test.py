# mr.typing

تطبيق عربي خفيف للتدرب على سرعة الكتابة ودقتها، بواجهة متجاوبة مستوحاة من أسلوب iOS الحديث وخط Cairo. يعمل التطبيق عبر FastAPI، وتُحمّل جولات التدريب من نقطة نهاية داخلية.

## الألعاب

- **سوالف:** مقاطع قصصية بمستويات سهل ومتوسط وصعب، مع 500 نص فريد لكل مستوى.
- **جريدة:** نصوص بأسلوب العناوين والأخبار، مع 400 نص فريد لكل مستوى.
- **جمل:** 400 جملة فريدة لكل مستوى.
- **تكرار:** اختر من 1 إلى 20 كلمة؛ تظهر كل كلمة ثلاث مرات متتالية. يتضمن المخزون 350 كلمة تدريبية فريدة.

اكتب **ابدا** لعرض قائمة الألعاب، أو اختر لعبة مباشرة. اكتب **وقف** لإلغاء العد التنازلي أو الجولة وإيقاف ردود البوت؛ اكتب **ابدا** مجددًا للاستئناف.

تدعم الواجهة العربية والإنجليزية، والسمة الداكنة والفاتحة. تُحفظ إحصاءات التدريب وتفضيلات المظهر واللغة في تخزين المتصفح على الجهاز نفسه. تبقى أقسام الحساب والمتصدرين والمجتمع وVIP ظاهرة كواجهات **قيد التجهيز** فقط؛ تسجيل الدخول وإنشاء الحساب وأزرار VIP معطّلة حتى إعداد خادم آمن. لا توجد حاليًا مزامنة سحابية أو نتائج مشتركة أو عمليات شراء.

## التشغيل محليًا

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```

افتح `http://127.0.0.1:8000`. في بيئة الاستضافة يمكن استخدام أمر التشغيل:

```bash
uvicorn main:app --host 0.0.0.0 --port $PORT
```

## فحوص المحتوى

```bash
python -m unittest discover -s tests
```

تتحقق الفحوص من أحجام مجموعات التدريب وتفرّد عناصرها، ومن تكرار كلمات الجولة ثلاث مرات والتحقق من حدود الاختيار.
