# mr.typing

منصة تدريب عربية/إنجليزية بـFastAPI: خمس تبويبات سفلية، رفيق كتابة بمحادثة كاملة المساحة، وحسابات وملفات شخصية ومجتمع ورسائل وتحديات مشتركة.

## ما تغيّر

- يُعرض النص العربي متصلًا، دون تقسيم الحروف إلى عناصر منفصلة. حقول الكتابة بحجم 16px على الأقل، ولا يُعطَّل تكبير المستخدم. يتكيف إطار التطبيق مع المساحة المرئية، ويُمرَّر سجل المحادثة داخله بدل تحريك الصفحة كلها.
- حسابات باسم مستخدم فريد من 3–24 حرفًا: حروف إنجليزية وأرقام ونقطة وشرطة سفلية، مع حرف واحد على الأقل. تُخزّن الأسماء بصيغتها الصغيرة ويُفرض التفرد في قاعدة البيانات. الاسم الظاهر منفصل وقابل للتعديل.
- صورة شخصية وصورة/اسم للبوت، وروابط Instagram وSnapchat وX، ومتابعة ومتابعة بالمثل وحظر، ورسائل خاصة وإشعارات، وبحث وإحصاءات وترتيب بالنقاط أو السرعة.
- تحديات خاصة برابط، وتحديات عامة حتى 8 مشاركين. يبدأها المضيف بعد انضمام لاعبين على الأقل؛ الهدف والعدّ التنازلي مشتركان، والوقت والنتيجة يُحسبان في الخادم.
- اقتراح ألعاب من إعدادات البوت، مع قائمة مراجعة للمدير. قبول الاقتراح يسجل قرارًا فقط؛ لا يشغّل كودًا مقترحًا ولا يتيح للمدير قراءة الرسائل الخاصة.

## التدريب المتتابع

اكتب **ابدا** أو **start**، ثم اختر اللعبة والمستوى. تستمر الجولات بعد إرسال الإجابة، حتى لو احتوت على أخطاء، إلى أن تكتب **وقف** أو تضغط زر الإيقاف. يُعرض ملخص سريع للسرعة والدقة والأخطاء والخصم قبل الجولة التالية.

في التكرار تظهر `(سيارة)3`، ويُكتب `سيارة سيارة سيارة`. اختر 1–20 كلمة. تُحسب المسافات ضمن الإجابة.

النقاط الأساسية تساوي عدد المحارف المرئية في الهدف؛ يُخصم **2** لكل خطأ حرف/رقم و**1** لكل خطأ مسافة/ترقيم، مع حد أدنى صفر. تُستخدم محاذاة تحريرية موزونة وتطبيع NFC؛ لا تُحذف الحركات العربية. WPM مبني على المحارف الصحيحة، والنتيجة المرسلة من العميل لا تُوثق. النتائج الأسرع من 300 WPM أو الأقصر من ثانية لا تدخل الترتيب العام؛ هذه حماية أولية وليست نظام مكافحة غش كاملًا.

## مولد النصوص

تُركّب الجولة عند الطلب، وليست اختيارًا من قائمة أهداف كاملة مخزنة. تستخدم تمارين الكلمات corpus من مكتبة `wordfreq`، وتستخدم النصوص مكونات لغوية محايدة قابلة للتركيب. توجد آلاف الاحتمالات، لكن التوليد **تركيبي وليس نموذج ذكاء اصطناعي خارجيًا**، ولا يضمن عدم التكرار عالميًا. نصوص «الجريدة» تدريب اصطناعي وليست أخبارًا حقيقية. بيانات corpus لها حدود لغوية، وقائمة تنقية الألفاظ ليست إشرافًا بشريًا شاملًا. راجع [إشعارات المصادر](THIRD_PARTY_NOTICES.md).

## التشغيل محليًا

مجرّب على Python 3.12. من جذر المستودع:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
SESSION_COOKIE_SECURE=false uvicorn main:app --reload
```

افتح `http://127.0.0.1:8000`. تعطيل Secure في الأمر أعلاه مخصص لـHTTP المحلي فقط؛ القيمة الافتراضية آمنة على كل المضيفين. إن لم يُضبط `DATABASE_URL` محليًا، تستخدم قاعدة SQLite في `data/local.db` (مستثناة من Git). ملف `.env.example` مرجع للإعدادات؛ التطبيق يقرأ متغيرات البيئة الفعلية ولا يحمّل ملف `.env` تلقائيًا.

## Render والتخزين الدائم

وجود Web Service لا يعني وجود قاعدة بيانات. [نظام ملفات Render الافتراضي مؤقت](https://render.com/docs/disks)، لذلك **يرفض التطبيق تشغيل الحسابات على Render دون `DATABASE_URL`** بدل إنشاء حسابات تضيع عند إعادة النشر.

في Environment للخدمة اضبط:

| المتغير | الاستخدام |
|---|---|
| `DATABASE_URL` | عنوان PostgreSQL الداخلي السري، من قاعدة مرتبطة في المنطقة/الحساب نفسيهما. لا تضعه في Git. |
| `ADMIN_USERNAME` | اسم المدير المحجوز قبل فتح التسجيل. |
| `ADMIN_BOOTSTRAP_PASSWORD` | كلمة مرور قوية من 10–128 محرفًا، تُستخدم فقط لإنشاء مدير جديد. لا توجد بيانات افتراضية. |
| `PUBLIC_URL` | اختياري عند استعمال نطاق مخصص؛ دون ذلك يُستخدم `RENDER_EXTERNAL_URL` الذي توفره Render. |
| `SESSION_COOKIE_SECURE` | افتراضيًا `true` على جميع المضيفين؛ يرفض التطبيق تعطيله على Render أو `PUBLIC_URL` من نوع HTTPS. |

أمر البناء: `pip install -r requirements.txt`

أمر التشغيل:

```bash
uvicorn main:app --host 0.0.0.0 --port $PORT --proxy-headers
```

فحص الصحة: `/healthz`. تُنشأ الجداول الأولية بطريقة غير مدمرة، مع قفل PostgreSQL لمنع سباق إنشاء المخطط. لا تحذف التهيئة بيانات قائمة ولا تحول مستخدمًا عاديًا إلى مدير تلقائيًا. خطط لترحيلات إصدارية قبل تغييرات المخطط اللاحقة. راجع [ربط PostgreSQL على Render](https://render.com/docs/postgresql-creating-connecting) و[المتغيرات الافتراضية](https://render.com/docs/environment-variables).

الصور تُفحص ويعاد ترميزها WebP بحجم 256×256، وتُحفظ نسختها الصغيرة في قاعدة البيانات، لا في قرص الخدمة المؤقت. الحد الأصلي 2MB؛ JPEG/PNG/WebP فقط. عند نمو المنصة، انقل الصور إلى تخزين كائنات وفعّل نسخًا احتياطية مناسبة لقاعدة البيانات.

## الأمان والخصوصية

كلمات المرور Argon2id؛ رمز الجلسة العشوائي في Cookie `HttpOnly` و`SameSite=Lax`، وتُحفظ تجزئته فقط في قاعدة البيانات. الطلبات المصادقة المغيّرة تحتاج CSRF، وتُفحص الصلاحيات في الخادم. مفاتيح الدخول لا تُحفظ في `localStorage`؛ اللغة والمظهر فقط محليان.

الملفات العامة والإحصاءات وروابط التواصل عامة. الرسائل خاصة بالمشاركين وفق صلاحيات التطبيق، لكنها **ليست مشفرة من طرف إلى طرف**. الإحصاءات القديمة الموجودة في متصفح واحد لا تُدمج تلقائيًا في الترتيب العام الجديد، ولا يمسح التطبيق مفاتيحها القديمة.

تتيح الإعدادات حذف الحساب نهائيًا بعد تأكيد كلمة المرور واسم المستخدم. حذف الحساب من قاعدة البيانات النشطة يحذف كذلك كل رسالة يكون الحساب مرسلها أو مستلمها، لدى جميع الأطراف، إضافةً إلى بيانات الحساب والجلسات والبيانات المرتبطة به. يُتاح اسم المستخدم للتسجيل مجددًا ما لم يكن محجوزًا للإدارة. لا يمحو ذلك نسخ قواعد البيانات الاحتياطية فورًا؛ على المشغّل تحديد مدة احتفاظ واضحة للنسخ وضمان انتهاء النسخ التي تحتوي البيانات بعد انقضائها. لا تتوفر حاليًا ميزة لتصدير بيانات الحساب.

هذا إصدار أولي متعدد المستخدمين، وليس ادعاء تدقيق أمني شامل. قبل توسيع التسجيل العام أضف استعادة كلمة المرور/التحقق من الحساب، وسياسة خصوصية واحتفاظ بالبيانات، وإبلاغًا وإشرافًا على الإساءة، واختبارات فعلية على iOS وAndroid. محدد المعدل داخل العملية مناسب لمثيل أولي؛ التوسع لعدة مثيلات يحتاج مخزنًا مشتركًا. الرسائل والتحديات تستخدم استطلاعًا دوريًا قصيرًا، لا WebSocket.

## الاختبارات

```bash
pip install -r requirements-dev.txt
PYTHONDONTWRITEBYTECODE=1 python -m unittest discover -s tests -v
node --check static/app.js
```

تغطي الاختبارات التوليد والتكرار والعربية والتقييم، وتفرد الحسابات وCSRF والملكية والرسائل والحظر والصور والتحديات وصلاحيات الإدارة. فحوص HTML/CSS لا تعادل اختبار لوحة مفاتيح iPhone فعلية.

## الملفات

`main.py` نقطة التشغيل. `typing_app/` للمنطق وقاعدة البيانات وAPI. `static/` للواجهة. `tests/` للاختبارات. لا يحتاج المشروع خدمة AI مدفوعة أو مفتاح نموذج لتشغيل رفيق التدريب.

لاختبارات التزامن على PostgreSQL محلي منفصل (لا تستخدم قاعدة إنتاج):

```bash
TEST_POSTGRES_URL=postgresql+psycopg://USER@127.0.0.1:55432/mt_test_typing \
  python -m unittest discover -s tests -p test_postgres.py -v
```

ترفض هذه الفحوص أي مضيف غير محلي أو اسم قاعدة لا يبدأ بـ`mt_test_`، وتُتخطى عند عدم ضبط المتغير.
